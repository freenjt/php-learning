The Functional Spectrum in PHP

PHP is a multi-paradigm language. Functional Programming treats computation as the evaluation of mathematical functions without mutable state.

First-Class Functions

Functions are values! Assignable to variables, passed as arguments, and returned from functions.

  • • $add = fn($a, $b) => $a + $b;
  • • First-Class Callables: strlen(...)
  • • Instances of \Closure
Purity & Determinism

Pure functions produce identical output for given input without causing side effects.

  • • No global variable mutation
  • • No I/O or database writes inside pure units
  • • Easy unit testing & memoization
Immutability

Data structures cannot be modified after creation. New transformed copies are returned.

  • • array_map() creates new arrays
  • • readonly class & immutable value objects
  • • Thread-safe & predictable state
Higher-Order Functions

Functions that accept other functions as arguments or return new functions.

  • • array_filter(), array_reduce()
  • • Custom higher-order wrappers
  • • Function factories & Currying
Pipelines & Composition

Chaining small single-purpose functions together to build complex data processing streams.

  • • pipe($f, $g, $h)($input)
  • • Point-free programming style
  • • Declarative step-by-step logic
Monadic Structures

Encapsulating side-effects, optional values (`Option`), or errors (`Either`) safely.

  • • Eliminates null checks
  • • Prevents try-catch exception noise
  • • Safe method chaining with flatMap()

Anonymous Functions, Closures & Arrow Functions

PHP provides traditional Anonymous Functions (`function() use(...)`) and concise Arrow Functions (`fn(...)`).

Anonymous Closure (`use` keyword) 
$taxRate = 0.20;

// Requires explicit variable binding via 'use'
$calculateTotal = function (float $price) use ($taxRate): float {
    return $price + ($price * $taxRate);
};

// Modifying $taxRate outside does NOT affect the captured copy by default!
$taxRate = 0.25; 
echo $calculateTotal(100); // Outputs: 120 (bound 0.20)

Variables captured by value. Use use (&$var) to capture by reference.

Arrow Functions (`fn` - Auto Scope Capture) 
$discount = 15;

// Automatically captures outer scope variables by-value!
$applyDiscount = fn(float $price): float => $price - $discount;

$prices = [100.0, 50.0, 200.0];

// Clean functional inline transformation
$discounted = array_map(fn($p) => $p - $discount, $prices);
// Output: [85.0, 35.0, 185.0]

Arrow functions consist of a single expression whose result is implicitly returned.

First-Class Callable Syntax (PHP 8.1+)

Turn any existing function, static method, or instance method directly into a first-class \Closure using the `...` syntax.

Native Function & Method Callables 
// 1. Internal built-in function as closure
$trim = trim(...);
$strlen = strlen(...);

$words = ["  apple ", " banana  ", "  cherry"];
$cleanWords = array_map($trim, $words); // ["apple", "banana", "cherry"]

// 2. Class static method as closure
$sanitizer = StringSanitizer::clean(...);

// 3. Object instance method as closure
$formatter = new MoneyFormatter();
$formatFn = $formatter->formatUSD(...);

Replaces verbose strings like 'trim' or array callables [$obj, 'method'] with full static analysis & type safety!

Legacy vs PHP 8.1+ Callable Syntax
Target Legacy Syntax PHP 8.1+ First-Class Syntax

Static Method ['Foo', 'bar'] Foo::bar(...)
Instance Method [$this, 'method'] $this->method(...)

Built-in Higher-Order Array Operations

The foundation of declarative data transformation in PHP: Map, Filter, and Reduce.

array_map()

Transforms every element of an array using a mapping function 1:1.

$nums = [1, 2, 3, 4];

// Element-wise transformation
$squares = array_map(
    fn($n) => $n * $n, 
    $nums
);
// Output: [1, 4, 9, 16]
Signature: (callable, array) -> array
array_filter()

Filters array items based on a boolean predicate function.

$nums = [1, 2, 3, 4, 5, 6];

// Keep only even numbers
$evens = array_filter(
    $nums, 
    fn($n) => $n % 2 === 0
);
// Output: [1 => 2, 3 => 4, 5 => 6]
Signature: (array, callable) -> array
array_reduce()

Folds an array into a single accumulated scalar or complex value.

$nums = [10, 20, 30];

// Sum accumulator
$total = array_reduce(
    $nums, 
    fn($acc, $item) => $acc + $item, 
    0
);
// Output: 60
Signature: (array, callable, initial) -> mixed

Function Composition & Custom Pipelining

Combine single-responsibility unary functions into elegant pipelines with pipe() and compose().

`pipe()` Function (Left-to-Right) 
/**
 * Left-to-right pipe function execution: f(x) -> g(f(x)) -> h(g(f(x)))
 */
function pipe(callable ...$fns): Closure {
    return fn(mixed $input): mixed => array_reduce(
        $fns,
        fn($acc, $fn) => $fn($acc),
        $input
    );
}

// Defining small pure transformations
$trim = fn(string $s) => trim($s);
$lowercase = fn(string $s) => strtolower($s);
$addExclamation = fn(string $s) => $s . "!";

// Compose into a single pipeline function
$processText = pipe($trim, $lowercase, $addExclamation);

echo $processText("  HELLO WORLD  "); // Outputs: "hello world!"
`compose()` Function (Right-to-Left) 
/**
 * Right-to-left compose execution (Mathematical logic): (f ∘ g)(x)
 */
function compose(callable ...$fns): Closure {
    return pipe(...array_reverse($fns));
}

$double = fn(int $n) => $n * 2;
$addFive = fn(int $n) => $n + 5;

// Compose: Executes $addFive FIRST, then passes result to $double
$doubleAfterAddFive = compose($double, $addFive);

echo $doubleAfterAddFive(10); // (10 + 5) * 2 = 30

Mathematical composition evaluates right-to-left: f(g(x)).

Currying & Partial Function Application

Currying converts a function with multiple arguments into a chain of single-argument functions.

Curried Add Function 
// Standard Multi-argument function: f(a, b)
$add = fn(int $a, int $b) => $a + $b;

// Curried Version: f(a)(b)
$curriedAdd = fn(int $a) => fn(int $b) => $a + $b;

// Partial Application: Preset $a = 10 to build specialized helper!
$addTen = $curriedAdd(10);

echo $addTen(5);  // Outputs: 15
echo $addTen(20); // Outputs: 30

// Useful in array_map!
$numbers = [1, 2, 3];
$incrementedByTen = array_map($addTen, $numbers); // [11, 12, 13]
Generic Partial Application Helper 
function partial(callable $fn, mixed ...$presetArgs): Closure {
    return fn(mixed ...$remainingArgs) => $fn(...$presetArgs, ...$remainingArgs);
}

$multiplyThree = fn(int $a, int $b, int $c) => $a * $b * $c;

// Preset first parameter $a = 2
$doubleProduct = partial($multiplyThree, 2);

echo $doubleProduct(3, 4); // 2 * 3 * 4 = 24

Partial application binds subset of arguments to return a simpler callable signature.

Pure Functions & Immutable Data Structures

Combining pure functions with PHP 8.2 readonly class creates side-effect-free domain models.

Impure (Side-Effects) 
$globalTax = 0.15;

// IMPURE: Depends on global state & mutates input!
function processOrderImpure(array &$order): void {
    global $globalTax;
    $order['tax'] = $order['total'] * $globalTax; // Mutation!
    $order['total'] += $order['tax'];
}

Hard to test, non-deterministic, mutates memory by reference.

Pure & Immutable Value Object 
readonly class Money {
    public function __construct(
        public float $amount,
        public string $currency = 'USD'
    ) {}

    // Pure method: Returns NEW instance, never mutates $this!
    public function add(Money $other): Money {
        return new Money($this->amount + $other->amount, $this->currency);
    }
}

$m1 = new Money(100.0);
$m2 = $m1->add(new Money(50.0)); // $m1 remains 100.0!

Thread-safe, predictable, easily tested in isolation.

Monadic Patterns: Eliminating Nulls with Option Monad

Monads encapsulate computation steps, allowing safe chaining without null checks or try-catch blocks.

Option Monad Implementation 
readonly class Option {
    private function __construct(private mixed $value) {}

    public static function some(mixed $val): self { return new self($val); }
    public static function none(): self { return new self(null); }

    public function isDefined(): bool { return $this->value !== null; }

    // Functor map: applies function if value exists
    public function map(callable $fn): self {
        return $this->isDefined() ? self::some($fn($this->value)) : self::none();
    }

    public function getOrElse(mixed $default): mixed {
        return $this->isDefined() ? $this->value : $default;
    }
}
Safe Monadic Pipeline 
function findUser(int $id): Option {
    $db = [1 => ['name' => 'Alice', 'email' => 'alice@php.net']];
    return isset($db[$id]) ? Option::some($db[$id]) : Option::none();
}

// Chain transformations safely without any nested "if ($user !== null)"!
$userEmail = findUser(1)
    ->map(fn($u) => $u['email'])
    ->map(fn($e) => strtolower($e))
    ->getOrElse('guest@php.net');

echo $userEmail; // Outputs: "alice@php.net"

// Searching missing ID 99 automatically falls back safely:
$missingEmail = findUser(99)
    ->map(fn($u) => $u['email'])
    ->getOrElse('guest@php.net'); // Outputs: "guest@php.net"

No null pointer exceptions or redundant checks.

Recursion & The Trampoline Pattern

PHP call stack depth is limited (~1000 frames). Trampolines turn deep recursion into stack-safe iterative loops.

Trampoline Function Loop 
/**
 * Trampoline executes thunks iteratively until a final scalar is returned.
 */
function trampoline(callable $fn): mixed {
    $result = $fn();
    while (is_callable($result)) {
        $result = $result(); // Unroll execution stack!
    }
    return $result;
}

// Tail-recursive Factorial returning thunks
function factorial(int $n, int $acc = 1): Closure|int {
    if ($n <= 1) return $acc;
    // Return closure (Thunk) instead of immediate deep call!
    return fn() => factorial($n - 1, $n * $acc);
}

// Stack-safe execution even for high recursion counts!
$res = trampoline(fn() => factorial(100));
Call Stack Comparison
Standard Recursion Stack Growth:
factorial(100) -> factorial(99) -> ... [Call Stack Overflow Risk!]
Trampolined Iterative Bounce:
Call Frame 1 -> returns Thunk -> Loop executes Thunk -> Frame 1 reused!

Prevents Zend Engine stack exhaustion on large recursive datasets.
