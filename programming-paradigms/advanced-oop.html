Constructor Promotion & Readonly Semantics

PHP 8.0 introduced Constructor Property Promotion, followed by Readonly Properties (PHP 8.1) and Readonly Classes (PHP 8.2).

Constructor Promotion & Readonly Classes 
// PHP 8.2+ Readonly Class automatically marks ALL properties readonly
readonly class UserDTO {
    // Constructor Property Promotion: defines and initializes in one step!
    public function __construct(
        public int $id,
        public string $name,
        public string $email,
        public DateTimeImmutable $createdAt = new DateTimeImmutable()
    ) {}
}

$user = new UserDTO(1, "Alice", "alice@php.net");
// $user->name = "Bob"; // Fatal Error: Cannot modify readonly property!
Engine Immutability Rule:

Readonly properties can only be initialized once, strictly within their defining class scope. Modifying them after initialization throws an \Error exception!

Property Visibility & Immutability Rules
Feature PHP Version Behavior Rule
Constructor Promotion PHP 8.0+ Infers property definition directly from `__construct` parameters.
Readonly Properties PHP 8.1+ Requires typed declaration. Write-once, immutable thereafter.
Readonly Classes PHP 8.2+ Implicitly marks every property as `readonly` and prevents dynamic props.
Asymmetric Visibility PHP 8.4+ Allows distinct `public private(set)` property access controls.

Property Hooks & Asymmetric Visibility (PHP 8.4+)

Property Hooks eliminate repetitive getter/setter boilerplate while providing virtual properties and controlled mutation.

Property Hooks Syntax (`get` / `set`) 
class UserProfile {
    public string $firstName = "John";
    public string $lastName = "Doe";

    // Virtual property calculated on demand with 'get' hook
    public string $fullName {
        get => "{$this->firstName} {$this->lastName}";
    }

    // Property with validation and transformation on 'set' hook
    public string $email {
        set (string $value) {
            if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
                throw new InvalidArgumentException("Invalid email format");
            }
            $this->email = strtolower(trim($value));
        }
    }
}

Encapsulates property access natively within property declarations.

Asymmetric Visibility (`public private(set)`) 
class BankAccount {
    // Public read access, but modification strictly private to class!
    public private(set) float $balance = 0.0;

    public function deposit(float $amount): void {
        if ($amount > 0) {
            $this->balance += $amount; // Allowed inside class
        }
    }
}

$account = new BankAccount();
$account->deposit(100.0);
echo $account->balance; // Outputs: 100
// $account->balance = 500.0; // Fatal Error: Cannot modify private(set) property!

Deep Dive into PHP Magic Methods

Magic methods intercept core object lifecycles, property accesses, dynamic invocations, and serialization.

Property & Call Interceptors 
class DynamicEntity {
    private array $data = [];

    public function __get(string $name): mixed {
        return $this->data[$name] ?? null;
    }

    public function __set(string $name, mixed $value): void {
        $this->data[$name] = $value;
    }

    public function __call(string $method, array $args): mixed {
        if (str_starts_with($method, 'getBy')) {
            $field = strtolower(substr($method, 5));
            return $this->data[$field] ?? null;
        }
        throw new BadMethodCallException("Method {$method} does not exist");
    }
}
Invocation, Cloning & Serialization 
class CallableService {
    // Allows object instance to be called directly like a function!
    public function __invoke(string $payload): string {
        return strtoupper($payload);
    }

    // Called on 'clone $obj' for deep copying nested objects
    public function __clone(): void {
        $this->internalState = clone $this->internalState;
    }

    // Modern custom serialization (PHP 7.4+)
    public function __serialize(): array {
        return ['clean' => $this->data];
    }
}

Interfaces & Type Variance Rules (Covariance & Contravariance)

PHP supports covariant return types (narrower in subtype) and contravariant parameters (wider in subtype).

Covariant Return Types (Narrower) 
abstract class Animal {}
class Dog extends Animal {}

interface AnimalFactory {
    public function create(): Animal; // Broader return
}

class DogFactory implements AnimalFactory {
    // Covariance: Dog is more specific than Animal -> VALID!
    public function create(): Dog {
        return new Dog();
    }
}

Subtype methods can return more specific types.

Contravariant Parameters (Wider) 
class AnimalShelter {
    public function adopt(Dog $dog): void {}
}

class UniversalShelter extends AnimalShelter {
    // Contravariance: Animal is wider/more general than Dog -> VALID!
    public function adopt(Animal $animal): void {}
}

Subtype methods can accept broader parameter types.

Traits Composition, Conflict Resolution (`insteadof`) & Aliasing

When multiple traits define identical method signatures, explicit conflict resolution is mandatory using insteadof.

Conflict Resolution (`insteadof` & `as`) 
trait LoggerA {
    public function log(string $msg): void { echo "A: $msg"; }
}

trait LoggerB {
    public function log(string $msg): void { echo "B: $msg"; }
}

class Application {
    use LoggerA, LoggerB {
        // Resolve conflict: choose LoggerA's log over LoggerB
        LoggerA::log insteadof LoggerB;
        // Alias LoggerB's log method to logToB with changed visibility
        LoggerB::log as private logToB;
    }
}

Prevents fatal method collisions during Zend compilation.

Trait Precedence Hierarchy
1 Current Class Methods (Highest Priority - Overrides Traits)
2 Trait Methods (Overrides Inherited Parent Methods)
3 Parent Class Inherited Methods (Lowest Priority)

Backed Enumerations with Methods & Interfaces (PHP 8.1+)

Enums in PHP are full-fledged objects that can back values, implement interfaces, and encapsulate methods.

Backed Enum with Interface 
interface HasLabel {
    public function getLabel(): string;
}

enum HttpStatus: int implements HasLabel {
    case OK = 200;
    case NOT_FOUND = 404;
    case SERVER_ERROR = 500;

    public function getLabel(): string {
        return match($this) {
            self::OK => '200 OK',
            self::NOT_FOUND => '404 Not Found',
            self::SERVER_ERROR => '500 Server Error',
        };
    }
}

$status = HttpStatus::from(404); // Instant hydration from backing int
echo $status->getLabel(); // Outputs: 404 Not Found

Includes built-in tryFrom() for safe non-exception parsing.

Built-in Enum Properties & Methods
  • $case->name : Returns case name as string (e.g., "NOT_FOUND")
  • $case->value : Returns backing primitive (e.g., 404)
  • EnumClass::cases() : Returns array of all defined enum cases
  • EnumClass::from($val) : Hydrates case or throws \ValueError

Modern Attributes & Reflection API (PHP 8.0+)

Attributes provide structured, native metadata directly inspectable through Reflection without parsing docblocks.

Defining & Applying Custom Attributes 
#[Attribute(Attribute::TARGET_METHOD | Attribute::TARGET_CLASS)]
class Route {
    public function __construct(
        public string $path,
        public string $method = 'GET'
    ) {}
}

#[Route('/api/users')]
class UserController {
    #[Route('/api/users/{id}', method: 'GET')]
    public function getUser(int $id): array {
        return ['id' => $id];
    }
}
Reflection Attribute Inspection 
$reflector = new ReflectionClass(UserController::class);
$attributes = $reflector->getAttributes(Route::class);

foreach ($attributes as $attribute) {
    // Instantiates the attribute instance directly!
    $routeInstance = $attribute->newInstance();
    echo "Path: " . $routeInstance->path; // "/api/users"
    echo "Method: " . $routeInstance->method; // "GET"
}

Source: php.net/language.attributes

Anonymous Classes & Dynamic Instantiation

Useful for lightweight, throwaway objects implementing interface contracts on the fly.

Anonymous Class Implementation 
interface LoggerInterface {
    public function log(string $msg): void;
}

// Instantiate anonymous class passing constructor arguments
$logger = new class('app.log') implements LoggerInterface {
    public function __construct(private string $filename) {}

    public function log(string $msg): void {
        echo "[{$this->filename}] {$msg}\n";
    }
};

$logger->log("Server Started"); // Outputs: [app.log] Server Started
Internal Engine Behavior

Each anonymous class declaration receives a unique compiler-generated internal name at runtime:

get_class($logger);
// Outputs e.g.: "class@anonymous/path/script.php:8$1b"
