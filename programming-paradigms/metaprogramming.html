The PHP Metaprogramming Spectrum

Metaprogramming allows code to treat other code as data, reading, generating, or modifying runtime behavior dynamically.

Overloading Hooks

Interpreting dynamic method calls and property reads/writes when members are undefined.

  • • __get($name) & __set($k, $v)
  • • __call($method, $args)
  • • Dynamic ORMs & Proxy classes
Reflection Engine

Full reverse-engineering of classes, interfaces, properties, methods, and docblocks at runtime.

  • • ReflectionClass inspection
  • • Invoking private methods/properties
  • • Auto-wiring DI containers
PHP 8+ Attributes

Structured native metadata attached to classes, methods, properties, and parameters.

  • • #[Attribute] declarations
  • • $ref->getAttributes()
  • • Declarative routing & validation
Dynamic Code Evaluation

Executing variable functions, variable variables, and dynamically constructing class instances.

  • • Variable variables $$var

  • • Factory instantiation new $class()
Closure Scope Binding

  • • Closure::bind() static factory
  • • Private scope inspection
  • • Dynamic DSL builder patterns
Serialization & Hydration

  • • __serialize() / __unserialize()
  • • var_export() & __set_state()
  • • Safe object state reconstruction

Property Overloading: `__get`, `__set`, `__isset`, `__unset`

Property overloading in PHP is triggered when accessing or mutating properties that are inaccessible or undeclared.

Dynamic Data Container Implementation 
class DynamicBag {
    private array $data = [];

    // Triggered when writing to inaccessible/non-existing properties
    public function __set(string $name, mixed $value): void {
        $this->data[$name] = $value;
    }

    // Triggered when reading inaccessible/non-existing properties
    public function __get(string $name): mixed {
        return $this->data[$name] ?? null;
    }

    // Triggered when calling isset() or empty()
    public function __isset(string $name): bool {
        return isset($this->data[$name]);
    }

    // Triggered when calling unset()
    public function __unset(string $name): void {
        unset($this->data[$name]);
    }
}

$bag = new DynamicBag();
$bag->role = "Administrator"; // Triggers __set
echo $bag->role;              // Triggers __get -> "Administrator"

Note: Overloading methods must be declared as public.

Guarding Against Engine Pitfalls
1. Strict Mode & Typed Overloading:

__set accepts mixed $value. Type validation must be handled manually inside the magic body.

2. Reference Modification Pitfall:

$bag->arr[] = 1; fails unless &__get() explicitly returns by reference!

3. Inaccessible Declared Properties:

If a property is private inside the class, external access fires __get, but inside class scope it accesses directly.

Source: php.net/language.oop5.overloading.members

Method Interception: `__call`, `__callStatic`, `__invoke`

Intercepting call attempts on undefined instance or static methods, or enabling objects to be invoked as callable functions.

Intercepting Calls & Dynamic Proxies 
class DynamicQueryBuilder {
    // Intercepts instance methods: $builder->whereName("Alice")
    public function __call(string $name, array $arguments): mixed {
        if (str_starts_with($name, 'where')) {
            $field = strtolower(substr($name, 5));
            return "WHERE {$field} = '" . $arguments[0] . "'";
        }
        throw new BadMethodCallException("Method {$name} does not exist.");
    }

    // Intercepts static method calls: DynamicQueryBuilder::findByName("Bob")
    public static function __callStatic(string $name, array $arguments): mixed {
        return "STATIC INTERCEPT: {$name} with args " . json_encode($arguments);
    }
}

$qb = new DynamicQueryBuilder();
echo $qb->whereEmail("user@php.net"); // WHERE email = 'user@php.net'
Invokable Classes (`__invoke`) 
class MoneyCalculator {
    public function __construct(private float $rate) {}

    // Allows the object instance to be called like a function!
    public function __invoke(float $amount): float {
        return $amount * $this->rate;
    }
}

$taxCalculator = new MoneyCalculator(1.20);

// $taxCalculator is a valid PHP callable!
echo is_callable($taxCalculator) ? 'YES' : 'NO'; // Outputs: YES
echo $taxCalculator(100.0);                      // Outputs: 120

Invokable objects can be passed directly to array_map() or pipeline higher-order functions.

Reflection API: Reverse Engineering Runtime Structures

PHP's built-in Reflection API lets you inspect, bypass accessibility restrictions, and dynamically construct components.

Class & Property Reflection 
class UserEntity {
    private string $secretHash = "A98F72D0";
}

$refClass = new ReflectionClass(UserEntity::class);

// Inspect class meta
echo $refClass->getShortName(); // "UserEntity"
echo $refClass->hasProperty('secretHash') ? 'Yes' : 'No';

// Inspect private property
$refProp = $refClass->getProperty('secretHash');

// PHP 8.1+ getSetValue or setAccessible()
$user = new UserEntity();
$refProp->setAccessible(true); // Bypass private encapsulation!
echo $refProp->getValue($user); // Outputs: "A98F72D0"
Dynamic Instantiation Without Constructor 
class HeavyService {
    public function __construct() {
        throw new Exception("Constructor should not run!");
    }
}

$ref = new ReflectionClass(HeavyService::class);

// Instantiate class WITHOUT calling its __construct!
$instance = $ref->newInstanceWithoutConstructor();

var_dump($instance instanceof HeavyService); // true

// Dynamically invoke method with parameters
$refMethod = $ref->hasMethod('run') ? $ref->getMethod('run') : null;
// $refMethod?->invokeArgs($instance, [$arg1, $arg2]);

Crucial technique used by ORMs (Doctrine) and Serializers to hydrate objects.

PHP 8 Attributes & Structural Metadata

Native structured metadata syntax replaces unstructured PHPDoc comments with type-safe metadata classes.

1. Attribute Definition & Target Flags 
#[Attribute(Attribute::TARGET_METHOD | Attribute::TARGET_PROPERTY)]
readonly class Route {
    public function __construct(
        public string $path,
        public string $method = 'GET'
    ) {}
}

// Attaching metadata to class members
class UserController {
    #[Route(path: '/api/users', method: 'GET')]
    public function index(): array {
        return ['status' => 'ok'];
    }
}

Targets: TARGET_CLASS, TARGET_METHOD, TARGET_PROPERTY, TARGET_PARAMETER.

2. Reading Attributes via Reflection 
$refMethod = new ReflectionMethod(UserController::class, 'index');

// Fetch ReflectionAttribute instances
$attributes = $refMethod->getAttributes(Route::class);

foreach ($attributes as $attribute) {
    // Instantiate attribute class dynamically!
    /** @var Route $route */
    $route = $attribute->newInstance();

    echo $route->method . ' -> ' . $route->path;
    // Outputs: "GET -> /api/users"
}

Attribute classes are only instantiated when calling newInstance(), maximizing performance.

Dynamic Mechanics & Variable Variables

PHP allows dynamic variable names, dynamic method invocation, dynamic class instantiation, and `eval()` execution.

Variable Variables & Dynamic Methods 
// Variable Variables ($$var)
$foo = 'bar';
$$foo = 'baz'; // Creates $bar = 'baz'
echo $bar;     // Outputs: "baz"

// Dynamic Function Calls
$fnName = 'strlen';
echo $fnName('PHP'); // Outputs: 3

// Dynamic Class Instantiation
$class = 'DateTime';
$now = new $class('now');

// Dynamic Property & Method Access
$prop = 'date';
echo $now->$prop;
`eval()` vs Anonymous Functions 
// RISKY: Executing raw PHP string code at runtime
$code = 'return 5 * 10;';
$result = eval($code); // 50

// SAFE METAPROGRAMMING ALTERNATIVE:
// Anonymous functions and First-Class Callables
$dynamicCalc = fn(int $a, int $b) => $a * $b;
echo $dynamicCalc(5, 10); // 50

eval() bypasses opcache optimizations and introduces severe security risks if user input is injected.

Closure Scope Binding & Private Hijacking

Closure::bind() rebinds a closure's instance bound object (`$this`) and class scope, granting access to private state.

Reading Private State via `Closure::bind()` 
class Vault {
    private string $pin = "9981";
}

$vault = new Vault();

// Define closure targeting private $pin
$readPin = function() {
    return $this->pin;
};

// Rebind closure to $vault instance AND Vault class scope!
$boundClosure = Closure::bind($readPin, $vault, Vault::class);

echo $boundClosure(); // Outputs: "9981"

Bypasses access controls without altering target class definition.

Immediate Call Binding (`Closure::call()`) 
class InternalConfig {
    private array $settings = ['debug' => true];
}

$config = new InternalConfig();

// Immediately bind and execute closure in one step!
$isDebug = (function() {
    return $this->settings['debug'];
})->call($config);

var_dump($isDebug); // bool(true)

Faster and more readable than creating intermediate bound closure instances.

Serialization, Hydration & Metaprogrammatic State

Controlling object serialization payloads with __serialize() / __unserialize() and code generation with __set_state().

Modern `__serialize()` & `__unserialize()` 
class SessionToken {
    public function __construct(
        private string $token,
        private DateTime $expiresAt
    ) {}

    // Returns custom serialized array payload
    public function __serialize(): array {
        return [
            'token' => $this->token,
            'exp' => $this->expiresAt->format('Y-m-d H:i:s')
        ];
    }

    // Reconstructs object state from array payload
    public function __unserialize(array $data): void {
        $this->token = $data['token'];
        $this->expiresAt = new DateTime($data['exp']);
    }
}
Code Export Hydration (`__set_state`) 
class ValueObject {
    public function __construct(public string $key, public int $val) {}

    // Called when code generated by var_export() is evaluated!
    public static function __set_state(array $array): self {
        return new self($array['key'], $array['val']);
    }
}

$obj = new ValueObject("timeout", 30);
$exportedCode = var_export($obj, true);
// Evaluates to: ValueObject::__set_state(array('key' => 'timeout', 'val' => 30))

Essential for building compiled configuration caches (e.g., Symfony Container cache).

Magic Constants & Dynamic Execution Context

Magic constants resolve dynamically based on the location where they are evaluated during compilation/execution.

Execution Scope Reflection Constants 
namespace App\Services;

class LoggerService {
    public function logEvent(): void {
        echo "Line: " . __LINE__ . "\n";        // Current line
        echo "File: " . __FILE__ . "\n";        // Full file path
        echo "Dir:  " . __DIR__  . "\n";        // Directory
        echo "Func: " . __FUNCTION__ . "\n";    // "logEvent"
        echo "Class:" . __CLASS__ . "\n";       // "App\Services\LoggerService"
        echo "Method:" . __METHOD__ . "\n";     // "App\Services\LoggerService::logEvent"
        echo "NS:   " . __NAMESPACE__ . "\n";  // "App\Services"
    }
}
Trait Scope Resolution (`__TRAIT__`) 
trait AuditLog {
    public function getCallerTrait(): string {
        // Resolves to the name of the Trait, NOT the consuming Class!
        return __TRAIT__;
    }
}

class UserHandler {
    use AuditLog;
}

$handler = new UserHandler();
echo $handler->getCallerTrait(); // Outputs: "AuditLog"

Useful when constructing diagnostic logs or framework telemetry.
