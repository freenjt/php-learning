Lexical Tokenization with `PhpToken` (PHP 8.0+)

The Tokenizer extension exposes Zend Engine's internal lexical scanner directly to PHP code.

Modern `PhpToken` Lexical Scanner 
<?php
$code = '<?php function add(int $a): int { return $a + 1; }';

// Tokenize code into PhpToken objects
$tokens = PhpToken::tokenize($code);

foreach ($tokens as $token) {
    if ($token->isIgnorable()) continue; // Skip comments/spaces
    
    echo sprintf(
        "Line %d: %s ('%s') [ID: %d]\n",
        $token->line,
        $token->getTokenName(),
        addcslashes($token->text, "\n\r\t"),
        $token->id
    );
}
php.net Spec: `PhpToken` Methods

$token->is($kind) tests token equality against ID, name, or string. $token->isIgnorable() returns true for T_WHITESPACE, T_COMMENT, or T_DOC_COMMENT.

`PhpToken` Object Properties
Property Type Description
$token->id int Zend Token Constant ID (e.g. T_FUNCTION or ASCII char)
$token->text string The exact textual source contents of the token
$token->line int 1-based line number where the token starts
$token->pos int 0-based character offset within the source code

Reflection API & Type System Introspection

Static analysis tools leverage PHP's Reflection classes to analyze types, signatures, and constraints.

Reflection Type Hierarchy Analysis 
<?php
class Service {
    public function process(int|float $val, string&Countable $item): void {}
}

$refMethod = new ReflectionMethod('Service', 'process');

foreach ($refMethod->getParameters() as $param) {
    $type = $param->getType();
    
    if ($type instanceof ReflectionUnionType) {
        echo "Union Type: " . implode('|', array_map(
            fn($t) => $t->getName(), $type->getTypes()
        )) . "\n";
    } elseif ($type instanceof ReflectionIntersectionType) {
        echo "Intersection Type: " . implode('&', array_map(
            fn($t) => $t->getName(), $type->getTypes()
        )) . "\n";
    }
}

Source: php.net/class.reflectiontype

Reflection Core Class Matrix
ReflectionNamedType

Represents simple standalone types (e.g., int, string, User). Method: getName().

ReflectionUnionType

Represents disjunctive types (A|B). Method: getTypes() returning array of subtypes.

ReflectionIntersectionType

Represents conjunctive types (A&B). Method: getTypes() returning combined interfaces.

ReflectionAttribute

Represents metadata annotations. Method: getArguments() without instantiating class.

Attribute-Driven Metadata Analysis (`ReflectionAttribute`)

Attributes provide structured, type-safe metadata without requiring docblock regex parsing.

Non-Instantiating Attribute Introspection 
<?php
#[Attribute(Attribute::TARGET_METHOD)]
class DeprecatedRule {
    public function __construct(public string $reason) {}
}

class ApiController {
    #[DeprecatedRule('Use v2 endpoint')]
    public function oldEndpoint(): void {}
}

// Reflection inspection WITHOUT instantiating class
$method = new ReflectionMethod('ApiController', 'oldEndpoint');
$attributes = $method->getAttributes('DeprecatedRule');

foreach ($attributes as $attr) {
    echo "Attribute: " . $attr->getName() . "\n";
    echo "Reason: " . $attr->getArguments()[0] . "\n";
}

Static analysis reads attribute arguments safely via getArguments() without triggering code execution!

Attribute::TARGET_FUNCTION Global Functions
Attribute::TARGET_METHOD Class Methods
Attribute::TARGET_PROPERTY Class Properties

Pre-compilation & OPcache Bytecode Verification

Validating script compilability programmatically using native OPcache API functions.

Programmatic OPcache Pre-Compilation 
<?php
$file = __DIR__ . '/src/App.php';

// Programmatically compile file into OPcache without executing
if (function_exists('opcache_compile_file')) {
    $success = @opcache_compile_file($file);
    
    if ($success) {
        echo "Script successfully compiled to opcodes!\n";
        echo "Is Cached: " . (opcache_is_script_cached($file) ? 'YES' : 'NO');
    } else {
        echo "Compilation failed! Syntax or type error present.\n";
    }
}

Syntax Error Interception (`ParseError` & `CompileError`)

Handling syntax failures programmatically using PHP 7+ catchable throwables.

Safe In-Process Syntax Linting 
<?php
function lintPhpCode(string $code): array {
    try {
        // Tokenize first to catch unclosed tokens
        $tokens = PhpToken::tokenize($code);
        
        // Evaluate syntax via token stream or compilation
        return ['valid' => true, 'error' => null];
    } catch (\ParseError $e) {
        return [
            'valid' => false,
            'error' => $e->getMessage(),
            'line'  => $e->getLine()
        ];
    } catch (\CompileError $e) {
        return [
            'valid' => false,
            'error' => "Compile Error: " . $e->getMessage(),
            'line'  => $e->getLine()
        ];
    }
}

Programmatic Static Type Checking Engine

How static analysis tools evaluate type compatibility using PHP type hierarchy rules.

Programmatic Subtype Assigner 
<?php
function isTypeAssignable(string $given, string $expected): bool {
    // 1. Exact Type Match
    if ($given === $expected) return true;
    
    // 2. Scalar widening (int is assignable to float)
    if ($given === 'int' && $expected === 'float') return true;
    
    // 3. Class Subclass / Implementation Check
    if (class_exists($given) && class_exists($expected)) {
        return is_subclass_of($given, $expected);
    }
    
    return false;
}
