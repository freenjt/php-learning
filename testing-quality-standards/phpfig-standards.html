PSR-1 & PER Coding Style: Core Mandates

Fundamental rules governing file structure, side effects, naming conventions, and modern PHP syntax rules.

PSR-1 Mandatory Rules 
<?php
// Files MUST use only <?php or <?= tags.
// Files MUST use UTF-8 without BOM.

namespace Vendor\Project;

// Classes MUST be in StudlyCaps
class TransactionProcessor
{
    // Class constants MUST be in ALL_CAPS with underscores
    public const MAX_RETRIES = 3;

    // Method names MUST be camelCase
    public function executePayment(): void
    {
        // Property names SHOULD be camelCase ($snake_case or $StudlyCaps allowed if consistent)
    }
}
Side Effect Rule:

A file SHOULD declare symbols (classes, functions, constants) OR execute side effects (echo, include, INI settings), but MUST NOT do both in the same file!

Modern PER CS (PHP 8+) Extensions 
<?php

declare(strict_types=1); // Exactly 1 blank line after, no space before semicolon

namespace App\Services;

use App\Contracts\ProcessorInterface;

// Constructor Property Promotion + Attributes (PER CS Standard)
#[Attribute(Attribute::TARGET_CLASS)]
final class OrderService implements ProcessorInterface
{
    public function __construct(
        private readonly PaymentGateway $gateway,
        private readonly LoggerInterface $logger,
    ) {} // Trailing comma on multiline parameter list!
}

PSR-4: Autoloading Standard Algorithm

Specification for mapping fully qualified class names (FQCN) to relative file system paths.

Fully Qualified Class Name (FQCN) Structure
\<VendorName>\(<SubNamespaceNames>)*\<ClassName>
  • 1. FQCN MUST have a top-level namespace name ("Vendor Name").
  • 2. FQCN MAY have one or more sub-namespaces.
  • 3. FQCN MUST end with a terminating class name.
  • 4. Underscores have NO special meaning in any portion (unlike legacy PSR-0).
  • 5. Case sensitivity MUST match file system paths exactly.
Source: php-fig.org/psr/psr-4
Reference PSR-4 Autoloader Implementation 
spl_autoload_register(function (string $class): void {
    $prefix = 'Foo\\Bar\\';
    $baseDir = __DIR__ . '/src/';

    $len = strlen($prefix);
    if (strncmp($prefix, $class, $len) !== 0) {
        return; // Move to next registered autoloader
    }

    $relativeClass = substr($class, $len);
    $file = $baseDir . str_replace('\\', '/', $relativeClass) . '.php';

    if (file_exists($file)) {
        require $file;
    }
});

Autoloaders MUST NOT throw exceptions when a file is not found.

PSR-3: Logger Interface & Message Interpolation

Establishes common logging contract with RFC-5424 severity levels and context message placeholders.

8 Standard RFC-5424 Log Severity Levels
1. emergency
2. alert
3. critical
4. error
5. warning
6. notice
7. info
8. debug
Exception Context Rule: If an \Throwable object is passed in context, it MUST be under the 'exception' key!
PSR-3 `LoggerInterface` Contract 
namespace Psr\Log;

interface LoggerInterface
{
    public function emergency(string|\Stringable $message, array $context = []): void;
    public function alert(string|\Stringable $message, array $context = []): void;
    public function critical(string|\Stringable $message, array $context = []): void;
    public function error(string|\Stringable $message, array $context = []): void;
    public function warning(string|\Stringable $message, array $context = []): void;
    public function notice(string|\Stringable $message, array $context = []): void;
    public function info(string|\Stringable $message, array $context = []): void;
    public function debug(string|\Stringable $message, array $context = []): void;
    public function log($level, string|\Stringable $message, array $context = []): void;
}

PSR-7: HTTP Message Interfaces & Value Objects

Provides standard representations for HTTP requests, responses, URIs, uploaded files, and streams.

Core PSR-7 Abstraction Interfaces
MessageInterface

Base protocol version, headers, stream body.

RequestInterface / ServerRequestInterface

Target URI, HTTP method, parsed body, query params.

ResponseInterface

Status code, reason phrase, response headers.

StreamInterface

Encapsulates body streams (`php://temp`, PSR-7 streams).

Source: php-fig.org/psr/psr-7

Strict Immutability Paradigm 
// HTTP messages are immutable value objects!
$response = new Response(200);

// Mutating methods MUST return a NEW instance!
$newResponse = $response
    ->withHeader('Content-Type', 'application/json')
    ->withStatus(201);

// $response remains UNCHANGED (200 OK, no headers)!
// $newResponse is a distinct clone instance (201 Created)!
Architectural Advantage:

Immutability prevents unexpected side effects when passing HTTP requests or responses through multiple middleware layers.

PSR-11: Container Interface Standard

Defines a minimal common interface for dependency injection containers and service locators.

`ContainerInterface` Definition 
namespace Psr\Container;

interface ContainerInterface
{
    /**
     * Finds an entry of the container by identifier and returns it.
     *
     * @throws NotFoundExceptionInterface  No entry found
     * @throws ContainerExceptionInterface  Error while retrieving entry
     */
    public function get(string $id): mixed;

    /**
     * Returns true if the container can return an entry for the given identifier.
     */
    public function has(string $id): bool;
}

Stoppable Event Implementation 
use Psr\EventDispatcher\StoppableEventInterface;

final class UserRegisteredEvent implements StoppableEventInterface
{
    private bool $stopped = false;

    public function __construct(public readonly User $user) {}

    public function stopPropagation(): void
    {
        $this->stopped = true;
    }

    public function isPropagationStopped(): bool
    {
        return $this->stopped;
    }
}

PSR-15: HTTP Server Request Handlers & Middleware

Defines interfaces for HTTP request handlers and middleware components using the "Onion Architecture" model.

PSR-15 Interfaces 
namespace Psr\Http\Server;

use Psr\Http\Message\ResponseInterface;
use Psr\Http\Message\ServerRequestInterface;

interface RequestHandlerInterface
{
    public function handle(ServerRequestInterface $request): ResponseInterface;
}

interface MiddlewareInterface
{
    public function process(
        ServerRequestInterface $request,
        RequestHandlerInterface $handler
    ): ResponseInterface;
}

Source: php-fig.org/psr/psr-15

Concrete Authentication Middleware 
final class AuthMiddleware implements MiddlewareInterface
{
    public function process(
        ServerRequestInterface $request,
        RequestHandlerInterface $handler
    ): ResponseInterface {
        if (!$request->hasHeader('Authorization')) {
            return new JsonResponse(['error' => 'Unauthorized'], 401);
        }

        // Delegate request down the pipeline to next handler
        $response = $handler->handle($request);

        // Add custom response header on outward pass
        return $response->withHeader('X-Auth-Verified', '1');
    }
}

Short-circuiting allows stopping requests immediately (e.g. returning 401).
