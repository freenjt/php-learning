PHP Filter Extension Taxonomy

The official PHP manual categorizes data filtering into core functional pillars.

Validation Filters

Verifies data integrity against expected criteria. Never mutates input.

  • • FILTER_VALIDATE_INT
  • • FILTER_VALIDATE_EMAIL
  • • FILTER_VALIDATE_URL / IP
Sanitization Filters

Cleans input data by stripping or encoding illegal characters.

  • • FILTER_SANITIZE_EMAIL
  • • FILTER_SANITIZE_NUMBER_INT
  • • FILTER_SANITIZE_SPECIAL_CHARS
Input Superglobal Access

Retrieves external superglobals directly without array lookup errors.

  • • filter_input(INPUT_POST, ...)
  • • filter_input(INPUT_GET, ...)
  • • filter_has_var(...)
Batch Array Schemas

Applies filter schemas across structured associative arrays.

  • • filter_var_array($arr, $schema)
  • • filter_input_array(...)
  • • FILTER_REQUIRE_ARRAY
Bitmask Flags & Options

Tweaks filter behavior using range options and bitmask flags.

  • • FILTER_FLAG_ALLOW_HEX / OCTAL
  • • FILTER_NULL_ON_FAILURE
  • • options => ['min_range' => 1]
Custom Callbacks

Executes custom procedural closures or class methods.

  • • FILTER_CALLBACK
  • • options => 'customFn'
  • • options => [$obj, 'method']

Validation Filters (`FILTER_VALIDATE_*`)

Validation filters verify if input meets specific expectations, returning typed values or false on failure.

Integer Range & Octal/Hex Flags 
$age = "25";
$validAge = filter_var($age, FILTER_VALIDATE_INT, [
    'options' => [
        'min_range' => 18,
        'max_range' => 65
    ]
]); // Returns (int) 25

$hex = "0xFF";
$validHex = filter_var($hex, FILTER_VALIDATE_INT, [
    'flags' => FILTER_FLAG_ALLOW_HEX
]); // Returns (int) 255
Official Rule:

On success, filter_var() returns the cast scalar value (e.g., int or float), NOT the original string representation.

Email & Internationalized URL Validation 
$email = "user@münchen.de";

// Standard validation fails on Unicode domains!
$valid1 = filter_var($email, FILTER_VALIDATE_EMAIL); // false

// Enhanced with Unicode Flag (PHP 7.1+):
$valid2 = filter_var(
    $email, 
    FILTER_VALIDATE_EMAIL, 
    FILTER_FLAG_EMAIL_UNICODE
); // "user@münchen.de"

Reference: php.net/filter.filters.validate

Sanitization Filters (`FILTER_SANITIZE_*`)

Sanitization filters modify input by stripping unwanted characters, preventing injection attacks.

Integer & Float Sanitization 
$rawId = "120abc-5!+";
$cleanId = filter_var($rawId, FILTER_SANITIZE_NUMBER_INT);
// Result: "120-5+" (Strips letters & punctuation)

$rawFloat = "price: -12.50 USD";
$cleanFloat = filter_var($rawFloat, FILTER_SANITIZE_NUMBER_FLOAT, [
    'flags' => FILTER_FLAG_ALLOW_FRACTION
]);
// Result: "-12.50"

Sanitization cleans string values but does NOT confirm semantic validity.

PHP 8.1+ Deprecation Notice 
// DEPRECATED in PHP 8.1+: FILTER_SANITIZE_STRING
// $str = filter_var($input, FILTER_SANITIZE_STRING);

// OFFICIAL PHP.NET RECOMMENDED REPLACEMENTS:
// 1. HTML Special Character Escaping
$safeHtml = filter_var($input, FILTER_SANITIZE_SPECIAL_CHARS);

// 2. Native htmlspecialchars()
$safeString = htmlspecialchars($input, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
Official Manual Note: FILTER_SANITIZE_STRING is deprecated as of PHP 8.1.0 and removed in PHP 8.4. Use FILTER_SANITIZE_SPECIAL_CHARS or htmlspecialchars() instead.

Bitmask Flags & `FILTER_NULL_ON_FAILURE`

Combining bitmask flags with bitwise OR (|) allows precise control over validation rules.

Bitwise Flag Composition 
$url = "https://example.org/path/to/resource?query=1";

// Combining flags using bitwise OR (|)
$flags = FILTER_FLAG_PATH_REQUIRED | FILTER_FLAG_QUERY_REQUIRED;

$validUrl = filter_var($url, FILTER_VALIDATE_URL, [
    'flags' => $flags
]);
// Returns URL string if path AND query are present, otherwise false
Boolean Validation Matrix:
• filter_var("yes", FILTER_VALIDATE_BOOLEAN) → true
• filter_var("off", FILTER_VALIDATE_BOOLEAN) → false
• filter_var("invalid", FILTER_VALIDATE_BOOLEAN, FILTER_NULL_ON_FAILURE) → null
Essential Filter Flag Constants
Flag Constant Target Filter Behavior
FILTER_NULL_ON_FAILURE BOOLEAN / General Returns null instead of false on failure.
FILTER_FLAG_ALLOW_OCTAL VALIDATE_INT Accepts octal notation (e.g. 0755).
FILTER_FLAG_IPV4 / IPV6 VALIDATE_IP Restricts IP validation to IPv4 or IPv6 format.
FILTER_FLAG_NO_ENCODE_QUOTES SANITIZE_SPECIAL_CHARS Leaves single/double quotes unescaped.

Reference: php.net/filter.filters.flags

Direct Superglobal Filtering (`filter_input`)

Safely retrieves and filters HTTP request parameters without inspecting raw superglobals directly.

Unsafe Superglobal Access 
// RISKY: Triggers Warning: Undefined array key "email" if missing!
$email = $_POST['email']; 

if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    // ...
}
  • • Throws PHP Notices if array keys are missing
  • • Requires cumbersome isset($_POST['key']) checks
  • • Subject to accidental superglobal mutation
Safe `filter_input()` Paradigm 
// SAFE: Returns NULL if missing, FALSE if invalid, STRING on success
$email = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL);

if ($email !== null && $email !== false) {
    echo "Valid posted email: {$email}";
}
  • • Returns null if variable is missing from request
  • • Returns false if validation fails
  • • Supports INPUT_GET, INPUT_POST, INPUT_COOKIE, INPUT_SERVER, INPUT_ENV

Batch Array Filtering (`filter_var_array`)

Validate or sanitize structured datasets against an associative array schema in a single operational step.

Associative Schema Definition 
$data = [
    'email' => 'user@example.com',
    'age'   => '28',
    'url'   => 'https://example.com'
];

$schema = [
    'email' => FILTER_VALIDATE_EMAIL,
    'age'   => [
        'filter'  => FILTER_VALIDATE_INT,
        'options' => ['min_range' => 18, 'max_range' => 65]
    ],
    'url'   => FILTER_VALIDATE_URL
];

$result = filter_var_array($data, $schema);

Source: php.net/function.filter-var-array

Validated Array Output 
/* $result Output Array:
Array
(
    [email] => user@example.com
    [age]   => 28
    [url]   => https://example.com
)
*/

// If any key fails, its value will be set to false (or null)
// If a key is missing from input, it is returned as NULL
Pro-Tip:

Pass $add_empty = false as second parameter to filter_input_array() to exclude missing keys from the returned result array.

Custom Callback Filtering (`FILTER_CALLBACK`)

Delegate custom data transformation and validation rules to procedural functions or OOP class methods.

Procedural Function Callback 
function formatUsername(string $value): string {
    return strtolower(trim($value));
}

$input = "  JohnDoe  ";

$clean = filter_var($input, FILTER_CALLBACK, [
    'options' => 'formatUsername'
]);

// Output: "johndoe"

Useful for custom string normalizations.

Class Method Callback 
class PhoneSanitizer {
    public static function clean(string $phone): string {
        return preg_replace('/[^0-9]/', '', $phone);
    }
}

$phone = "(123) 456-7890";

$digits = filter_var($phone, FILTER_CALLBACK, [
    'options' => [PhoneSanitizer::class, 'clean']
]);

// Output: "1234567890"

Enables modular, object-oriented validation logic.

Checking Input Existence (`filter_has_var`)

Checks if a variable of a specified superglobal type exists in the raw HTTP request payload.

Request Existence Checking 
// Checks raw request payload BEFORE any script modification
if (filter_has_var(INPUT_POST, 'submit')) {
    echo "Form submitted via POST";
}

if (filter_has_var(INPUT_GET, 'token')) {
    echo "URL contains GET token";
}

Source: php.net/function.filter-has-var

`filter_has_var()` vs `isset()`

1. Raw Input Inspection: filter_has_var() checks the actual HTTP request content sent by the client, ignoring user modifications to $_POST or $_GET inside your script.

2. Performance: Fast C-level execution avoiding PHP array hash lookups.

Building Strongly-Typed Filter DTO Pipelines

Encapsulating PHP filter functions into modern, strongly-typed domain objects.

Immutable User Input DTO 
readonly class UserRegistrationRequest {
    public string $email;
    public int $age;

    public static function fromRequest(): self {
        $email = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL)
            ?: throw new \InvalidArgumentException('Invalid email');

        $age = filter_input(INPUT_POST, 'age', FILTER_VALIDATE_INT, [
            'options' => ['min_range' => 18]
        ]) ?: throw new \InvalidArgumentException('Must be 18+');

        $dto = new self();
        $dto->email = $email;
        $dto->age = $age;
        return $dto;
    }
}
