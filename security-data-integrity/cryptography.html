PHP Cryptographic Subsystem Architecture

The official PHP documentation categorizes core cryptographic functions into 5 distinct primary API families.

CSPRNG Core

Cryptographically Secure Pseudo-Random Number Generation.

  • • random_bytes(int $length)
  • • random_int(int $min, int $max)
  • • OS Entropy integration (/dev/urandom)
Sodium (Libsodium)

Modern, misuse-resistant core cryptography library bundled in PHP 7.2+.

  • • sodium_crypto_secretbox() (AEAD)
  • • sodium_crypto_sign() (Ed25519)
  • • sodium_crypto_pwhash() (Argon2)
Password Hashing API

High-level secure key-stretching and password storage abstraction.

  • • password_hash()
  • • password_verify()
  • • password_needs_rehash()
Hash Extension & HMAC

Direct message digest algorithms, HMAC generation, and constant-time checks.

  • • hash_hmac('sha256', ...)
  • • hash_equals() (Timing Safe)
  • • hash_pbkdf2() (Key Derivation)
OpenSSL Extension

Full wrapper around OpenSSL for legacy & symmetric/asymmetric algorithms.

  • • openssl_encrypt() / openssl_decrypt()
  • • openssl_pkey_new() (RSA/EC)
  • • openssl_sign() / openssl_verify()
Core Design Rules

Official recommendations from php.net regarding cryptographic safety.

  • • Prefer Sodium for symmetric AEAD
  • • Never use rand() or mt_rand() for keys
  • • Use hash_equals() to stop timing attacks

CSPRNG: Secure Randomness Generation

PHP provides built-in, cross-platform functions connected directly to system entropy sources (e.g. /dev/urandom or Windows CNG API).

CSPRNG Function Usage 
<?php
// 1. Generate cryptographic binary bytes (for nonces/keys/salts)
$bytes = random_bytes(32); // 32 bytes = 256 bits
$hexKey = bin2hex($bytes); // Safe string representation

// 2. Generate a secure random integer in a closed range [min, max]
$token = random_int(100000, 999999); // Cryptographic 6-digit OTP

// 3. Handling Entropy Exception Hazards
try {
    $secureBytes = random_bytes(16);
} catch (\Random\RandomException $e) {
    // Thrown if insufficient system entropy sources exist
    log_error("Entropy source failed: " . $e->getMessage());
}

Source: php.net/manual/en/book.csprng.php

php.net Strict Rule:

Never use rand(), mt_rand(), or uniqid() for cryptographic security, password reset tokens, or secret key generation!

Standard Password Hashing API

PHP provides an abstraction API that automatically handles salt generation, algorithm agility, and cost factor parameters.

`password_hash` & `password_verify` 
<?php
$userPassword = 'SuperSecretUserPassword123!';

// 1. Hash password using default algorithm (currently Bcrypt or Argon2id)
$hash = password_hash($userPassword, PASSWORD_DEFAULT, [
    'cost' => 12 // Cost factor for Bcrypt iteration scaling
]);

// Resulting string format contains algo ID, cost, salt, and hash payload
// Example: $2y$12$eImiTXuWVxfM37uY4JANjO...

// 2. Constant-time verification against hash string
if (password_verify($userPassword, $hash)) {
    echo "Authentication successful!";
} else {
    echo "Invalid password credentials!";
}

Automatic random salt management prevents rainbow table attacks.

Automatic Rehashing & Upgrades 
<?php
// When verifying during user login:
if (password_verify($passwordInput, $existingHash)) {
    
    // Check if system cost factor or algorithm has upgraded
    if (password_needs_rehash($existingHash, PASSWORD_ARGON2ID, [
        'memory_cost' => 65536,
        'time_cost'   => 4,
        'threads'     => 1
    ])) {
        // Transparently rehash without requiring user password change
        $newHash = password_hash($passwordInput, PASSWORD_ARGON2ID);
        $userDatabase->updatePasswordHash($userId, $newHash);
    }
}
Supported Algorithms (php.net):
  • • PASSWORD_BCRYPT: Standard Blowfish hash ($2y$)
  • • PASSWORD_ARGON2I: Argon2i Memory-hard algorithm
  • • PASSWORD_ARGON2ID: Hybrid Argon2 (Resistant to GPU/Side-channel)

Message Integrity, HMAC & Timing Attack Safety

How to produce message authentication codes using HMAC and prevent side-channel timing leaks via hash_equals().

HMAC Message Authentication 
<?php
$secretKey = random_bytes(32); // Shared cryptographic secret
$payload   = 'action=transfer&amount=5000&recipient=8921';

// Generate Hash-based Message Authentication Code (HMAC)
$hmac = hash_hmac('sha256', $payload, $secretKey);

// HMAC verifies BOTH message integrity AND authenticity
echo "HMAC: " . $hmac;

Source: php.net/function.hash-hmac

Constant-Time Comparison (`hash_equals`) 
<?php
$expectedHmac = $_SESSION['expected_hmac'];
$userHmac     = $_POST['hmac_token'];

// VULNERABLE: Standard string equality == or === leaks timing info!
// if ($expectedHmac === $userHmac) { ... } 

// SECURE: Constant-time comparison stops timing attack measurements
if (hash_equals($expectedHmac, $userHmac)) {
    echo "Valid HMAC signature!";
} else {
    echo "Signature mismatch!";
}
Why `===` fails:

Standard string comparison stops checking at the first mismatched byte, leaking execution duration that attackers can exploit to forge signatures byte-by-byte!

Modern Authenticated Symmetric Encryption (Sodium AEAD)

Libsodium is built into PHP 7.2+. sodium_crypto_secretbox provides authenticated encryption (XSalsa20 + Poly1305).

`sodium_crypto_secretbox` Usage 
<?php
// 1. Generate 256-bit Secret Key
$key = sodium_crypto_secretbox_keygen(); // 32 bytes

// 2. Generate 192-bit Nonce (Number Used Once)
$nonce = random_bytes(SODIUM_CRYPTO_SECRETBOX_NONCEBYTES); // 24 bytes

$message = "Top Secret Payroll Record $150,000";

// 3. Authenticated Encryption (Confidentiality + Authentication)
$ciphertext = sodium_crypto_secretbox($message, $nonce, $key);

// 4. Decryption & Verification
$decrypted = sodium_crypto_secretbox_open($ciphertext, $nonce, $key);

if ($decrypted === false) {
    throw new Exception("Ciphertext tampered or invalid key!");
}
echo "Decrypted: " . $decrypted;

Sodium automatically prepends authentication tags, rendering tampering detectable.

Nonce & Key Safety Constraints
  • NEVER Reuse a Nonce with the Same Key:

    Reusing a nonce in secretbox destroys stream cipher confidentiality and allows message reconstruction!

  • Nonce Storage:

    Nonces are NOT secret! It is standard practice to prepend the nonce to the ciphertext string for transport.

  • Memory Zeroing (`sodium_memzero`):

    Wipe raw key material from PHP RAM: sodium_memzero($key);

Source: php.net/manual/en/book.sodium.php

OpenSSL Symmetric & Asymmetric Operations

OpenSSL provides extensive support for standard cipher modes (AES-256-GCM) and public/private RSA keys.

AES-256-GCM via OpenSSL 
<?php
$cipher = "aes-256-gcm";
$key = random_bytes(32);
$iv  = random_bytes(openssl_cipher_iv_length($cipher));

$data = "Sensitive Credit Card Payload";
$tag = ""; // Passed by reference to capture Auth Tag

// 1. Encrypt & Generate Authentication Tag
$ciphertext = openssl_encrypt($data, $cipher, $key, OPENSSL_RAW_DATA, $iv, $tag);

// 2. Decrypt & Authenticate
$decrypted = openssl_decrypt($ciphertext, $cipher, $key, OPENSSL_RAW_DATA, $iv, $tag);

if ($decrypted === false) {
    throw new Exception("Authentication tag validation failed!");
}

Always specify an AEAD mode like GCM or CCM when using OpenSSL.

Asymmetric Key Generation & Signatures 
<?php
// 1. Generate RSA Public/Private Keypair
$res = openssl_pkey_new([
    "private_key_bits" => 4096,
    "private_key_type" => OPENSSL_KEYTYPE_RSA,
]);
openssl_pkey_export($res, $privateKey);
$pubKey = openssl_pkey_get_details($res)["key"];

// 2. Sign payload with Private Key
$data = "Contract Agreement Text";
openssl_sign($data, $signature, $privateKey, OPENSSL_ALGO_SHA256);

// 3. Verify signature with Public Key
$ok = openssl_verify($data, $signature, $pubKey, OPENSSL_ALGO_SHA256);
// $ok === 1 if signature is valid!

Source: php.net/manual/en/book.openssl.php

Key Derivation Functions (PBKDF2 & Argon2)

Key derivation converts low-entropy user passwords into high-entropy master keys for symmetric ciphers.

`hash_pbkdf2()` Derivation 
<?php
$passphrase = "UserMasterPassphrasephrase";
$salt = random_bytes(16); // Unique cryptographic salt

// Derive a 256-bit (32-byte) key for AES encryption
$derivedKey = hash_pbkdf2(
    algo: "sha256",
    password: $passphrase,
    salt: $salt,
    iterations: 600000, // OWASP recommended iteration count
    length: 32,
    binary: true
);

// $derivedKey is now safe for openssl_encrypt or sodium_crypto_secretbox

Source: php.net/function.hash-pbkdf2

Argon2 Key Derivation via Sodium 
<?php
$passwd = "UserPassphrase";
$salt = random_bytes(SODIUM_CRYPTO_PWHASH_SALTBYTES);

// Memory-hard Argon2id key derivation
$key = sodium_crypto_pwhash(
    length: 32,
    password: $passwd,
    salt: $salt,
    opslimit: SODIUM_CRYPTO_PWHASH_OPSLIMIT_INTERACTIVE,
    memlimit: SODIUM_CRYPTO_PWHASH_MEMLIMIT_INTERACTIVE,
    alg: SODIUM_CRYPTO_PWHASH_ALG_ARGON2ID13
);
PBKDF2 vs Argon2id:

PBKDF2 is CPU-bound only and susceptible to GPU farm cracking. Argon2id enforces memory hardness, preventing hardware acceleration attacks!

Ed25519 Digital Signatures (`sodium_crypto_sign`)

Ed25519 provides ultra-fast, high-security elliptic curve digital signatures resistant to side-channel analysis.

Signing & Verifying Payloads 
<?php
// 1. Generate Ed25519 Keypair
$keypair = sodium_crypto_sign_keypair();
$secretKey = sodium_crypto_sign_secretkey($keypair);
$publicKey = sodium_crypto_sign_publickey($keypair);

$message = "Authorize Wire Transfer: $2,500,000";

// 2. Sign message with secret key
$signedMessage = sodium_crypto_sign($message, $secretKey);

// 3. Verify signed payload with public key
$original = sodium_crypto_sign_open($signedMessage, $publicKey);

if ($original === false) {
    throw new Exception("Signature invalid or tampered!");
}
echo "Verified: " . $original;

Detached signatures can also be created using sodium_crypto_sign_detached().
