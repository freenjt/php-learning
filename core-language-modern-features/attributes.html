Attribute Architecture & Core Concepts

Attributes provide structured, machine-readable metadata embedded directly into source declarations in PHP 8.0+.

Native Syntax `#[...]`

Replaces legacy docblock comments (`@param`, `@annotation`) with first-class tokenized engine syntax.

  • • Tokenized as T_ATTRIBUTE
  • • Validated by compiler parser
  • • Prevents docblock string parsing errors
Declarative Targets

Can be applied to classes, methods, functions, parameters, properties, and class constants.

  • • Attribute::TARGET_CLASS
  • • Attribute::TARGET_METHOD
  • • Attribute::TARGET_PROPERTY
Lazy Evaluation

Attributes are parsed into AST during compile time but instantiated ONLY when queried via Reflection.

  • • Zero execution overhead at boot
  • • Instantiated via ->newInstance()
  • • Arguments stored as raw AST nodes
Positional & Named Arguments

Supports literal values, constants, array expressions, and nested attribute instances (PHP 8.1+).

  • • #[Route('/api', method: 'GET')]
  • • Constant expressions allowed
  • • Enums and arrays supported
Class Representation

Every custom attribute is defined as a standard PHP class decorated with the #[Attribute] attribute.

  • • Constructor receives arguments
  • • Type safety for arguments
  • • Normal class inheritance applies
Reflection Inspection

Retrieved via reflection objects using getAttributes() returning ReflectionAttribute arrays.

  • • Filter by class name or flags
  • • Inspect arguments without instantiating
  • • Check repeatability status

Attribute Syntax Rules & BNF Specifications

Attributes start with #[ and end with ]. Multiple attributes can be declared on one line or separated across lines.

Valid Attribute Syntaxes 
<?php
// 1. Single attribute without arguments
#[ExampleAttribute]
class Service {}

// 2. Attribute with positional and named arguments
#[ListensTo('user.created', priority: 10)]
function onUserCreated() {}

// 3. Grouped attributes inside one #[ ... ] delimiter
#[AttrOne, AttrTwo('config'), AttrThree(enabled: true)]
class MultiAttributeClass {}

// 4. Nested Attributes (PHP 8.1+)
#[Assert\All([
    new Assert\NotBlank(),
    new Assert\Length(min: 3)
])]
protected array $names;
Comment Backwards Compatibility Note:

In PHP < 8.0, #[ was parsed as a single-line comment beginning with #. In PHP 8.0+, #[ is tokenized as T_ATTRIBUTE!

Allowed Syntactic Locations
Target Example Placement
Class / Enum / Trait #[Entity] class User {}
Property #[Column] public string $name;
Method / Function #[Get('/users')] public function index()
Parameter function set(#[Sensitive] $pass)
Class Constant #[Deprecated] const MAX = 100;

Defining Custom Attribute Classes

To define a custom attribute, declare a class decorated with #[Attribute] and configure its target mask flags.

Custom Attribute Class Definition 
<?php

namespace App\Attributes;

use Attribute;

#[Attribute(Attribute::TARGET_METHOD | Attribute::TARGET_FUNCTION | Attribute::IS_REPEATABLE)]
class Route
{
    public function __construct(
        public string $path,
        public string $method = 'GET',
        public int $priority = 0
    ) {}
}

Constructor promoted properties are automatically populated when newInstance() is invoked.

`Attribute::TARGET_*` Bitmask Constants
Attribute::TARGET_CLASS 1 (Bit 0)
Attribute::TARGET_FUNCTION 2 (Bit 1)
Attribute::TARGET_METHOD 4 (Bit 2)
Attribute::TARGET_PROPERTY 8 (Bit 3)
Attribute::TARGET_PARAMETER 16 (Bit 4)
Attribute::TARGET_CLASS_CONSTANT 32 (Bit 5)
Attribute::TARGET_ALL 63 (Bits 0-5)
Attribute::IS_REPEATABLE 64 (Bit 6)

Reading Attributes with Reflection API

Attributes are accessed using getAttributes() on Reflection objects, returning an array of ReflectionAttribute instances.

Querying Reflection Attributes 
<?php

$reflector = new ReflectionClass(UserController::class);

// 1. Fetch ALL attributes on class
$allAttributes = $reflector->getAttributes();

// 2. Filter attributes by specific class name
$routeAttributes = $reflector->getAttributes(Route::class);

// 3. Filter with inheritance check flag
$subAttributes = $reflector->getAttributes(
    BaseAttribute::class, 
    ReflectionAttribute::IS_INSTANCEOF
);

foreach ($routeAttributes as $refAttr) {
    // Instantiate actual attribute object
    $route = $refAttr->newInstance();
    echo $route->path; // Outputs path value
}
`ReflectionAttribute` Method Interface
getName(): string

Returns the target attribute class name string.

getArguments(): array

Returns raw arguments passed in syntax without instantiating class.

newInstance(): object

Instantiates attribute class, passing arguments into constructor.

isRepeated(): bool

Returns true if this attribute was repeated on target declaration.

getTarget(): int

Returns target bitmask allowed for this attribute.

Official Built-in Engine Attributes

PHP provides core engine attributes to alter compiler checks, deprecations, and parameter security behavior.

#[Override] PHP 8.3+

Ensures a method with the same name exists in a parent class or interface.

#[Override]
public function render(): void {}
#[SensitiveParameter] PHP 8.2+

Redacts parameter value in backtraces to protect secrets.

function login(
  #[SensitiveParameter] $pass
) {}
#[AllowDynamicProperties] PHP 8.2+

Suppresses deprecation notices for undeclared property creation.

#[AllowDynamicProperties]
class StdData {}
#[ReturnTypeWillChange] PHP 8.1+

Suppresses return type compatibility warnings during PHP core evolution.

#[ReturnTypeWillChange]
public function offsetGet($o) {}
#[Deprecated] PHP 8.4+

Triggers E_USER_DEPRECATED notice when function/method is invoked.

#[Deprecated(
  message: "Use v2()", 
  since: "1.2"
)]
#[Attribute] PHP 8.0+

Declares that a class can be used as an attribute.

#[Attribute(
  Attribute::TARGET_CLASS
)]

Nested Attributes & Expression Arguments (PHP 8.1+)

Since PHP 8.1, attribute arguments can include new expressions allowing nested attribute instances.

Nested Attribute Construction 
<?php

#[Attribute]
class Option {
    public function __construct(public string $name) {}
}

#[Attribute]
class Menu {
    public function __construct(public array $options) {}
}

// Nested attribute initialization inside argument list:
#[Menu(options: [
    new Option(name: 'Save'),
    new Option(name: 'Load')
])]
class EditorPanel {}
Allowed Attribute Expression Types
  • Scalar Literals: Strings, integers, floats, booleans, null.
  • Class Constants & Enums: MyClass::CONST or Status::Active.
  • Array Expressions: Multi-dimensional arrays with keys/values.
  • New Expressions (PHP 8.1+): Instantiating sub-objects directly.
