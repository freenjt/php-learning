PHP Control Structure Taxonomy

The official language specification categorizes statement flow into 6 core execution paradigms.

Conditional Branching

Evaluates boolean conditions to select execution paths.

  • • if / elseif / else
  • • switch (...) { case ... }
  • • match ($expr) { ... } (PHP 8.0+)
Iterative Loops

Repeats execution blocks based on predicates or collections.

  • • while & do-while
  • • for ($i; $cond; $inc)
  • • foreach ($arr as $k => &$v)
Jump & Loop Interrupts

Alters loop continuation or transfers instruction pointer.

  • • break $n; (Exits $n nested levels)
  • • continue $n; (Skips $n loop cycles)
  • • goto label; (Scoped jump)
Compiler Directives

Sets directives for execution blocks or entire scripts.

  • • declare(strict_types=1);
  • • declare(ticks=1);
  • • declare(encoding='UTF-8');
Exception / Jump Expressions

Handles exceptional states and expression throwing.

  • • try ... catch ... finally
  • • throw $e as Expression (PHP 8.0+)
  • • return $val;
Yielding & Fibers

Cooperative multitasking and generator control delegation.

  • • yield $key => $value
  • • yield from $iterable
  • • Fiber::suspend() / resume()

`foreach` Semantics, Reference Hazards & Array Unpacking

Deep dive into iteration mechanisms, reference modification safety, and structured destructuring.

The `foreach` Reference Dangling Trap 
$numbers = [1, 2, 3];

// Iterating by reference
foreach ($numbers as &$value) {
    $value *= 2;
}
// $value is STILL a reference to $numbers[2]!

// Second iteration without reference unexpectedly overwrites $numbers[2]!
foreach ($numbers as $value) {
    // $numbers[2] gets mutated during loop!
}

// MANDATORY FIX as per php.net:
unset($value); // Destroys the dangling reference!

Always call unset($value) immediately after a reference loop!

Array Destructuring in `foreach` 
$records = [
    [1, 'Alice', 'Admin'],
    [2, 'Bob', 'Editor'],
];

// Destructuring nested arrays directly in loop signature
foreach ($records as list($id, $name, $role)) {
    echo "ID: {$id}, Name: {$name}, Role: {$role}\n";
}

// Short syntax destructuring (PHP 7.1+)
foreach ($records as [$id, $name, $role]) {
    // Exact same effect
}

Numeric Scope Rules 
$i = 0;
while (++$i) {
    switch ($i) {
        case 1:
            echo "Iteration 1\n";
            break 1; // Exits switch only!
        case 2:
            echo "Iteration 2 - Exiting Loop\n";
            break 2; // Exits switch AND enclosing while loop!
        default:
            break;
    }
}
Switch Behavior Note:

In PHP, switch is considered a looping structure for break and continue! Thus continue 1 inside a switch acts identically to break 1.

`switch` Statement vs. `match` Expression (PHP 8.0+)

Fundamental comparison between legacy loose statement branching and modern strict expression evaluation.

`switch` Statement (Loose `==`) 
$val = '0';

// Switch uses loose comparison (==)
switch ($val) {
    case 0:
        $res = 'Matched integer 0'; // SURPRISE MATCH!
        break;
    case '0':
        $res = 'Matched string "0"';
        break;
}
// Outputs: Matched integer 0
  • • Uses loose equality (==)
  • • Requires explicit break; statements
  • • Statement (does NOT return a value)
  • • Quietly ignores unhandled values
`match` Expression (Strict `===`) 
$val = '0';

// Match uses strict identity (===) & returns value
$res = match ($val) {
    0 => 'Matched integer 0',
    '0' => 'Matched string "0"', // Correct Match!
    default => 'Unhandled',
};
// Outputs: Matched string "0"
  • • Uses strict identity (===)
  • • No fallthrough (no break needed)
  • • Expression (returns evaluated value)
  • • Throws \UnhandledMatchError if unhandled

The `declare` Directives (`strict_types`, `ticks`, `encoding`)

Used to set execution directives for a block of code or an entire file.

`strict_types=1` 
declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}

// Throws TypeError!
add(1, "2");

Enforces strict scalar type checking for function calls originating from the file.

Scope: File-level directive

`ticks=N` 
declare(ticks=1);

// Executes tick_handler() every N
// low-level tick statements
register_tick_function('handler');

$a = 1; // Tick!
$b = 2; // Tick!

Fires event callbacks during low-level engine tick events (used for signal handling).

Scope: Block or File

`encoding='...'` 
declare(encoding='ISO-8859-1');

// Instructs zend_compiler 
// how script characters 
// are encoded per file.

Specifies character encoding per-script for the compiler parser.

Scope: File-level directive

The `goto` Operator: Rules & Scope Restrictions

Jump statement that moves instruction execution to a named label within the same file and target scope.

Valid `goto` Usage 
// Breaking out of deeply nested logic cleanly
for ($i = 0; $i < 100; $i++) {
    while ($data = fetchData()) {
        if ($data->hasCriticalError()) {
            goto cleanup; // Jumps directly out
        }
    }
}

cleanup:
echo "Performing emergency cleanup actions...";

Jumping out of loops or switch statements is fully permissible.

Illegal Scope Jump (Compiler Error) 
// CANNOT jump INTO a loop or function!
goto inside_loop; // Compile Error!

while ($x < 10) {
    inside_loop:
    echo "Inside loop";
}

// CANNOT jump into another function or closure!
function test() {
    target_label:
    echo "Function";
}
goto target_label; // Compile Error!

Official Rule: Target label must reside in the exact same file and function scope!

`throw` as an Expression (PHP 8.0+)

Converted `throw` from a statement into an expression, enabling exception throwing inside expression contexts.

Modern Throw Expressions 
// 1. Null Coalescing Operator
$value = $input['key'] ?? throw new \InvalidArgumentException('Missing key');

// 2. Short Arrow Functions
$fn = fn($val) => $val > 0 ? $val : throw new \DomainException('Value <= 0');

// 3. Ternary Operators
$user = $session->getUser() ?: throw new \UnauthenticatedException();

// 4. Match Expression Arms
$result = match ($status) {
    200 => 'OK',
    default => throw new \UnexpectedValueException("Invalid status: {$status}"),
};

Generator Delegation Syntax 
function subGenerator() {
    yield 'B';
    yield 'C';
}

function mainGenerator() {
    yield 'A';
    yield from subGenerator(); // Yield delegation!
    yield 'D';
}

foreach (mainGenerator() as $letter) {
    echo $letter; // Outputs: A B C D
}

Fibers: Asynchronous Flow Control (PHP 8.1+)

Fibers represent interruptible full-stack coroutines, pausing execution without blocking the main event loop.

Fiber Suspend / Resume Lifecycle
sequenceDiagram autonumber participant Main as Main Call Stack participant Fiber as Fiber Context Main->>Fiber: Fiber::start() Note over Fiber: Executes till suspend Fiber->>Main: Fiber::suspend('paused_data') Note over Main: Main thread handles I/O Main->>Fiber: Fiber::resume('resumed_data') Note over Fiber: Finish execution Fiber-->>Main: Return final value
Native Fiber Coroutine 
$fiber = new Fiber(function (string $msg): void {
    echo "Fiber Started: {$msg}\n";
    
    // Suspend fiber execution and send data back to main thread
    $input = Fiber::suspend('suspended_value');
    
    echo "Fiber Resumed with: {$input}\n";
});

// Start fiber
$copied = $fiber->start('Init'); // "Fiber Started: Init"
echo "Main Received: {$copied}\n"; // "Main Received: suspended_value"

// Resume fiber execution
$fiber->resume('Payload'); // "Fiber Resumed with: Payload"
