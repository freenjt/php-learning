Type Declarations & Variance Rules

Type declarations apply to parameters, return values, class properties, and class constants (PHP 8.3+). Covariance and Contravariance govern inheritance rules.

Type Declaration Locations 
<?php

class UserStore {
    // 1. Class Constant Type Declaration (PHP 8.3+)
    public const string DRIVER = 'pdo_mysql';

    // 2. Property Type Declaration
    private readonly int $id;

    // 3. Parameter and Return Type Declarations
    public function findUser(int $id, ?string $tenant): ?User {
        return null;
    }
}
Subtyping Variance Specifications
Return Types are Covariant (Narrower)

A child class method may return a MORE SPECIFIC type than its parent method (e.g. parent returns Animal, child returns Dog).

Parameter Types are Contravariant (Wider)

A child class method parameter may accept a MORE GENERAL type than its parent (e.g. parent accepts Dog, child accepts Animal).

Property Types are Invariant

Class property types MUST match exactly upon inheritance to preserve read/write type consistency.

Coercive Typing vs. Strict Typing

By default, PHP operates in Coercive Typing Mode. Adding declare(strict_types=1); forces strict scalar type checking for function callers.

Engine Behavior Comparison
Input -> Target Coercive Mode Strict Mode (`strict_types=1`)
`"42"` -> `int` Coerces to `42` Throws `TypeError`
`1` -> `float` Coerces to `1.0` Accepted (`int` -> `float` allowed)
`1.5` -> `int` Coerces to `1` (Deprecated warning) Throws `TypeError`
`"hello"` -> `int` Throws `TypeError` Throws `TypeError`
Scope Rule: Strict typing applies to function calls Made From the file with declare(strict_types=1), not where the function is declared!
`declare(strict_types=1)` Syntax 
<?php
declare(strict_types=1); // Must be the first statement in file!

function calculateTax(float $amount, float $rate): float {
    return $amount * $rate;
}

// Allowed in strict mode: int passed to float parameter
echo calculateTax(100, 0.20); // Output: 20.0

// Throws TypeError in strict mode: string passed to float
echo calculateTax("100", 0.20); 
// Uncaught TypeError: calculateTax(): Argument #1 ($amount) 
// must be of type float, string given

Union Types (`TypeA|TypeB`)

Introduced in PHP 8.0. Accepts values that satisfy AT LEAST ONE of the specified type members.

Union Type Syntax & Rules 
<?php

// Accept int or float or string
function processInput(int|float|string $data): int|float {
    if (is_string($data)) {
        return strlen($data);
    }
    return $data * 2;
}

// Standalone null & false in unions (PHP 8.0+)
function findItem(string $query): Item|false|null {
    return false;
}
Disallowed Redundant Unions:
• bool|false (false is redundant with bool)
• object|User (User is redundant with object)
• mixed|int (mixed includes all types)

Intersection Types (`TypeA&TypeB`)

Introduced in PHP 8.1. Values must satisfy ALL specified type constraints simultaneously (Strictly Object/Interface types).

Pure Intersection Syntax 
<?php

interface Loggable { public function log(): void; }
interface Serializable { public function serialize(): string; }

// Value must implement BOTH Loggable AND Serializable!
function processEntity(Loggable&Serializable $entity): void {
    $entity->log();
    echo $entity->serialize();
}
Intersection Restrictions:
• Scalars (int, string) are NOT allowed in intersections.
• void, mixed, never are invalid in intersections.

Disjunctive Normal Form (DNF Types)

Introduced in PHP 8.2. Allows combining Union and Intersection types by structuring them as Unions of Intersections: (A&B)|C.

DNF Syntax Specification 
<?php

interface HasTitle { public function getTitle(): string; }
interface HasContent { public function getContent(): string; }

// DNF Type: Must be (HasTitle AND HasContent) OR null
function publishArticle((HasTitle&HasContent)|null $post): void {
    if ($post !== null) {
        echo $post->getTitle();
    }
}

// Complex DNF: (A&B) | (C&D) | String
function processData((HasTitle&HasContent)|(Countable&ArrayAccess)|string $input): void {}
DNF Strict Grammar Rules
Parentheses Required around Intersections:

(A&B)|C is valid. A&B|C is a syntax error!

Must follow Standard DNF Form:

Intersections MUST be grouped inside the Union. You cannot nest Unions inside Intersections like (A|B)&C.

Redundancies are Disallowed:

Duplicate segments such as (A&B)|(B&A) throw compile-time errors.

Special & Standalone Types

PHP provides unique standalone types including never, void, mixed, null, false, and true.

never (Bottom Type) PHP 8.1+

Indicates function NEVER returns (always throws exception or exits).

function redirect(): never {
    header('Location: /');
    exit();
}
void (Return Only) PHP 7.1+

Indicates function returns no value (can return or end naturally).

function logMsg(): void {
    // Return with no val
    return;
}
mixed (Top Type) PHP 8.0+

Equivalent to array|bool|callable|int|float|null|object|resource|string.

function inspect(
  mixed $val
): mixed { return $val; }
true & false (Standalone) PHP 8.2+

Used as standalone types (e.g., functions returning strictly true or false).

function alwaysTrue(): true {
    return true;
}
null (Standalone) PHP 8.2+

Standalone null type declaration (replaces legacy dummy returns).

function doNothing(): null {
    return null;
}
?Type (Nullable Shorthand) PHP 7.1+

Syntactic sugar for union with null: ?string is identical to string|null.

function get(?string $k) {}

Compound Types & Enum Integration

PHP handles arrays, iterables, callables, objects, and Enums within its unified type system.

Iterable, Callable & Enum Declarations 
<?php

// 1. Enum as typed value (PHP 8.1+)
enum Status: string {
    case Pending = 'P';
    case Approved = 'A';
}

function updateStatus(Status $status): void {}

// 2. iterable: array|Traversable
function processItems(iterable $items): void {
    foreach ($items as $item) {}
}

// 3. callable: anonymous function or array callback
function execute(callable $callback): void {
    $callback();
}
Engine Compound Rules
iterable Pseudo-Type:

Built-in alias for array|Traversable. Cannot be used in intersection types.

callable Restrictions:

Cannot be used as a property type declaration because callables depend on execution context.

Enum Subtyping:

Enums are object types under the hood (UnitEnum / BackedEnum) and satisfy object type hints.

Type Errors & The `TypeError` Exception

When type enforcement fails, PHP throws a \TypeError (subclass of \Error).

Catching `TypeError` 
<?php

declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}

try {
    // Throws TypeError in strict mode
    echo add(5, "10"); 
} catch (TypeError $e) {
    echo "Type Error Caught: " . $e->getMessage();
}
Sensitive Parameter Protection (PHP 8.2+):

Use #[SensitiveParameter] to prevent secret parameter values from leaking into TypeError stack traces!
