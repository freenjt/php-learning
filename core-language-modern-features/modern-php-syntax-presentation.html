PHP 8.0: Core Paradigm Shift

Engine modernizations that removed boilerplate and established strong strict typing.

Constructor Promotion & Named Args 
class Point {
    // Constructor Property Promotion
    public function __construct(
        public float $x = 0.0,
        public float $y = 0.0,
        public float $z = 0.0,
    ) {}
}

// Named Arguments (Order Independent)
$point = new Point(z: 15.5, x: 2.5);

function processInput(int|float|string $val): int|float {
    return is_string($val) ? strlen($val) : $val * 2;
}

// Nullsafe Operator (?->)
$country = $session?->user?->getAddress()?->country;

PHP 8.0: The `match` Expression

Unlike switch, match evaluates strictly (===), returns values, and doesn't require fallthrough break statements.

Decision Logic Architecture
graph TD A[Input Expression] --> B{Strict === Check} B -->|Arm 1 Match| C[Execute Single Expression & Return] B -->|Arm 2 Match| D[Execute Single Expression & Return] B -->|No Match| E{Has default arm?} E -->|Yes| F[Return Default Value] E -->|No| G[Throw UnhandledMatchError]
`match` Syntax Example 
$statusCode = 404;

$message = match ($statusCode) {
    200, 201 => 'Success',
    400 => 'Bad Request',
    404 => 'Not Found',
    500 => 'Server Error',
    default => 'Unknown Status',
};

// Throws \UnhandledMatchError if unhandled and no default arm!

Source: php.net/control-structures.match

PHP 8.1: First-Class Enums & Fibers

Native Enumerations replace custom class constants with full type safety.

Backed Enums & Methods 
enum Status: string {
    case DRAFT = 'draft';
    case PUBLISHED = 'published';
    case ARCHIVED = 'archived';

    public function label(): string {
        return match($this) {
            self::DRAFT => 'Draft Document',
            self::PUBLISHED => 'Publicly Visible',
            self::ARCHIVED => 'Archived Copy',
        };
    }
}

$status = Status::from('published');
echo $status->label(); // "Publicly Visible"

Source: php.net/language.enumerations

First-Class Callables & Intersection Types 
// First-class callable syntax (...)
$fn = strlen(...); // Creates a Closure from native function

// Readonly property (immutable after init)
class User {
    public readonly int $id;
    public function __construct(int $id) { $this->id = $id; }
}

// Intersection Types (&)
function countItems(Countable&Iterator $collection): int {
    return count($collection);
}

PHP 8.1: Fiber Scheduling & Flow

Fibers represent interruptible full-stack coroutines for non-blocking asynchronous I/O frameworks.

Fiber Coroutine Execution Loop
sequenceDiagram autonumber participant Main as Main Thread participant Fiber as Fiber Context Main->>Fiber: Fiber::start() Note over Fiber: Executes code... Fiber->>Main: Fiber::suspend($value) Note over Main: Main process continues I/O Main->>Fiber: Fiber::resume($result) Note over Fiber: Finish execution Fiber-->>Main: Return final value
Native Fiber Example 
$fiber = new Fiber(function (): void {
    echo "Fiber started\n";
    $value = Fiber::suspend('interrupted');
    echo "Fiber resumed with: {$value}\n";
});

$value = $fiber->start();
echo "Main thread received: {$value}\n";
$fiber->resume('re-entry payload');

/* Output:
Fiber started
Main thread received: interrupted
Fiber resumed with: re-entry payload
*/

Source: php.net/language.fibers

PHP 8.2: Type System Completeness

Readonly classes, DNF types, standalone literal types, and security sensitive parameters.

Readonly Classes & DNF Types 
// Readonly class enforces all properties to be readonly
readonly class ValueObject {
    public function __construct(
        public string $title,
        public int $amount
    ) {}
}

// Disjunctive Normal Form (DNF) Types combining & and |
function render((HasTitle&HasAuthor)|null $entity): void {
    if ($entity !== null) {
        echo $entity->getTitle();
    }
}

Source: php.net/language.types.declarations

#[\SensitiveParameter] & Literal Types 
// Redacts plain-text passwords in stack traces
function login(
    string $username,
    #[\SensitiveParameter] string $password
): false|UserSecret {
    // Return types false and null can be standalone types
    if ($username !== 'admin') {
        return false;
    }
    return new UserSecret();
}

PHP 8.3: Typed Constants & #[\Override]

Strict interface adherence, native high-performance JSON validation, and dynamic constant fetches.

Class Constant Types & #[\Override] 
interface Config {
    public const string VERSION = '1.0.0';
}

class AppConfig implements Config {
    // Enforces string type compatibility!
    public const string VERSION = '2.1.0';

    #[\Override] // Emits compile error if parent method is renamed
    public function isValid(): bool {
        return true;
    }
}

Source: php.net/manual/en/migration83.new-features.php

json_validate() & Dynamic Constant Fetch 
// High performance JSON syntax validator without memory allocation
$isValid = json_validate('{"name": "PHP 8.3"}'); // true

// Dynamic class constant fetching syntax
class MyClass {
    public const DEBUG = true;

$constName = 'DEBUG';
echo MyClass::{$constName}; // Access constant dynamically!

PHP 8.4: Property Hooks & Asymmetric Visibility

The biggest OOP advancement since PHP 5! Eliminates verbose getter and setter boilerplate natively.

Native Property Hooks (`get` & `set`) 
class UserProfile {
    public string $first;
    public string $last;

    // Derived Property Hook with Virtual GET
    public string $fullName {
        get => "{$this->first} {$this->last}";
    }

    // Property Hook with Mutation SET
    public string $email {
        set(string $value) => strtolower(trim($value));
    }
}

Source: php.net/language.oop5.propertyhooks

Asymmetric Visibility & `array_find()` 
class BankAccount {
    // Public read access, but Private write access!
    public private(set) float $balance = 0.0;

    public function deposit(float $amt): void {
        $this->balance += $amt;
    }
}

// New array_find helpers
$users = [['id' => 1, 'role' => 'admin'], ['id' => 2, 'role' => 'editor']];
$admin = array_find($users, fn($u) => $u['role'] === 'admin');

Source: php.net/language.oop5.visibility-members-asymmetric

Interactive Verification 
class Product {
    public float $price {
        set {
            if ($value < 0) {
                throw new \InvalidArgumentException('Price cannot be negative');
            }
            $this->price = round($value, 2);
        }
    }
}

$p = new Product();
$p->price = 19.998;
echo $p->price; // Outputs: 20
